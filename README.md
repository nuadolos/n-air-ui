## Локальный запуск

Понадобятся Node.js 22.12+ и npm. В папке проекта выполните:

```bash
npm ci
npm run dev
```

Откройте адрес из вывода Vite, обычно [http://localhost:5173](http://localhost:5173). 

## Ограничения демонстрации

**Кнопка «Оплатить» не проводит платёж и не списывает деньги.** Можно вводить вымышленные реквизиты: любой номер из 16 цифр, будущий месяц и год, CVC из 3 цифр. Например, `1111 2222 3333 4444` и CVC `123`. Данные карты не сохраняются и не отправляются на сервер. Настоящие реквизиты не нужны.

**Регистрация и вход имитируют авторизацию.** Можно указать вымышленные имя, фамилию, email в корректном формате и любой пароль от 6 символов. Например, `user@example.com`. Пароль не сохраняется и не проверяется сервером; подтверждать почту не нужно. Настоящий аккаунт не создаётся.

Билеты доступны в профиле до перезагрузки страницы. Пользователь и корзина сохраняются в браузере. Письма на почту не отправляются.

## Пример использования

Основной сценарий — от выбора рейса до онлайн-регистрации:

1. Откройте каталог. При желании выберите авиакомпанию, бюджет и сортировку, затем нажмите «Применить».
2. Нажмите «Выбрать рейс», посмотрите условия перелёта и добавьте билет в корзину.
3. Перейдите к оформлению. Войдите или выберите вкладку «Регистрация» и заполните данные профиля.
4. Проверьте имя и фамилию пассажира, введите вымышленные реквизиты карты и нажмите «Оплатить».
5. После оформления откроется профиль с билетом, номером бронирования и назначенным местом.
6. Нажмите «Зарегистрироваться» на билете — после подтверждения появится статус «Регистрация пройдена».
